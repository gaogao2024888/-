# 按旋律填词

把一段旋律变成「每句几个字、哪里押韵、哪里拖长音」的模板，按模板写词，再用脚本校验到全部对上。

脚本是本技能目录下的 `scripts/melody_lyrics.py`（调用技能时显示的 Base directory 就是本目录）。用 `uv run` 运行会自动装好依赖；没有 uv 就先 `pip install librosa soundfile mido pypinyin`，再用 `python3` 运行。

## 1. 准备旋律

| 用户手上有 | 怎么做 |
|---|---|
| 清唱、哼唱、人声分轨（wav/mp3/m4a/flac…） | 直接用，最准 |
| 带伴奏的整首歌 | 直接用。脚本会自动发现伴奏，改用 Melodia 从整首歌里提主旋律（要 essentia：Linux 上 `uv run` 自动安装，Windows 装不了）。比清唱差一些：伴奏和人声一样响时，偶尔会混进伴奏的音。要更准就先分离人声：本地 `demucs --two-stems=vocals 歌.mp3`、UVR 桌面版或 AudioPod 插件 |
| MIDI（Basic Pitch、SOME、扒谱软件、编曲工程导出） | 直接用，最准。多轨会自动挑人声/旋律轨，也可 `--track N` 指定 |

音频里有原唱时：

- 脚本只听旋律，**不识别原来的歌词**，也不会沿用。
- 原唱每唱一个字，通常就是模板里的一个音，所以每句字数大致等于原词字数。原唱一个字拖好几个音（拖腔）的地方，模板会多出格子，填词时用 `~` 让一个字占多个音。
- 和声、伴唱可能被当成旋律扒进来，说唱和念白扒出来的音高没有意义。遇到这些段落，用 `--start/--end` 避开。

音频扒谱是近似结果：个别音会偏一个半音，连音可能被拆开或合并。对填词来说**字数比音高要紧**：分句或字数拿不准时，请用户对着原曲哼一遍确认，或者让他们给 MIDI。

## 2. 生成填词模板

```bash
uv run <本技能目录>/scripts/melody_lyrics.py extract <音频或MIDI> [-o 模板.json]
```

常用参数：

- `--bpm 92`：自动测速常常差一倍，用户知道速度就填上
- `--gap 0.3`：断句的最短停顿（秒）。句子被拆碎就调大，两句粘成一句就调小
- `--max-notes 14`：一句超过这么多音，就从中间的长音处拆成两句
- `--start 30 --end 75`：只分析某一段（秒），比如只填副歌
- `--track N`：MIDI 选轨（输出里列了编号）
- `--mode vocal` / `--mode mix`：有没有伴奏默认自动判断，模板开头会写判断结果。用户说过是清唱还是整首歌，就直接指定（清唱、哼唱、人声分轨用 vocal，带伴奏用 mix）

输出一份 Markdown 模板，另存 `<文件名>.melody.json` 供校验用。动笔前先把调性、速度、句数和每句字数告诉用户，问一句分句对不对。

## 3. 按模板写词

先问清主题、情绪、人称和用途。用户要改现成歌词时，保留他们点名要留的句子。

- **一音一字**：第 N 句有几个音就写几个字。一个字要唱多个音（拖腔）时，在字后面加 `~`，每个 `~` 多占一个音，例如 `爱~~` 占 3 个音。
- **◆ 句尾韵脚**：同一段尽量押同一个辙（十三辙），副歌可以换辙。韵脚别用轻声字（的、了、吗）。
- **■ 长音**：放开口音（a、o、e、ai、ao、ang、an），别放 i、u、ü，高音尤其如此。
- **旋律重复的句子**（模板标了「旋律同第 N 句」）：字数和断句节奏保持一致，听起来才整齐。
- **依字行腔，防倒字**：上行大跳（⇑）落到的高音别放第三声字，下行大跳（⇓）落到的音别放第二声字，否则容易听成别的字。歌名、副歌钩子词和句尾要优先顾到，普通位置不必死抠。
- 粤语填词对音高要求严得多（0243 规则），本工具只给普通话提示。

把歌词写进文本文件，一行对应模板一句。`[主歌]`、`【副歌】` 这类整行标签会被跳过，括号里的和声不计字数。

## 4. 校验，改到全部对上

```bash
uv run <本技能目录>/scripts/melody_lyrics.py check <模板.json> <歌词.txt>
```

它会逐句报告字数对不对、韵脚和辙，列出长高音上的闭口音和可能的倒字，并给出简谱和歌词的逐字对照表。有 ✗ 的句子改完再跑，直到全部 ✓。提示类问题自己判断取舍，保留时向用户说明理由。

## 5. 交付

给用户三样东西：按段落分好的最终歌词、逐句简谱对照表（直接用 check 的输出）、简短的押韵说明。要拿去 Suno 生成的话，如果有 `suno-audit` 技能，先按它做一遍交稿前检查。

给现成歌曲填新词，自己唱着玩没问题；公开发布或商用前，旋律需要原作者授权。
