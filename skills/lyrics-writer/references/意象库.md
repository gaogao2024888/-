# 意象库

按笔记里的启动练习建三个文件夹。条目全是我自己写的，以后边写边加。

每个条目都要做到：意思通，画面对，念着顺。

## 一、动作的暴力（特别的动词搭配）

| 普通写法 | 换成 | 用的方法 |
|---|---|---|
| 天黑了 | 夜色把街灯一盏盏按亮 | 动词「按」 |
| 等了很久 | 茶在杯里凉成了一面镜子 | 「凉成」把时间变成画面 |
| 你走了 | 门把你的背影咬了一口 | 门「咬」背影：关门那一下 |
| 想说又不敢 | 那句话在舌头上搁浅 | 动词嫁接：航海词 + 舌头 |
| 下雨 | 雨把窗户缝了一整夜 | 动词嫁接：针线 + 雨 |
| 记得你 | 你的名字在我手机里生了根 | 动词嫁接：植物 + 手机 |
| 心动 | 心跳踩空了一拍 | 动词嫁接：走路 + 心跳 |
| 很晚了 | 末班车把月亮拖进了终点站 | 动词「拖」 |

## 二、物的情绪（拟人化的东西）

| 情绪 | 对应的东西 |
|---|---|
| 暗恋 | 输入框里打了又删的那一行；耳机分你一半时，那根被拉直的线 |
| 不敢开口 | 攥出汗的电影票；在门口来回踱了三圈的鞋 |
| 想念 | 另一只一直没洗的杯子；手机里舍不得删的语音 |
| 等待 | 被按亮又熄灭的屏幕；一盏为人留着的玄关灯 |
| 心动 | 两人走路时慢慢对齐的步子；她忘在我这里的发圈 |

## 三、声音的形状（通感）

| 句子 | 用的感官 |
|---|---|
| 你的笑声是刚剥开的橘子 | 声音写成味道和气味 |
| 你叫我名字的时候，像有人往雪里放了一颗糖 | 声音写成温度和触感 |
| 雨声是灰色的毛线，越织越长 | 声音写成颜色和形状 |
| 你说晚安，尾音软得像晒过的被子 | 声音写成触感 |
