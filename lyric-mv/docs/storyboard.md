# 《木生遇淑柔》歌词动画 MV —— 方案与分镜

## 1. 时间对齐结论

| 项目 | 结果 |
|---|---|
| 歌曲时长 | 3:24.62（204.6 秒） |

## 2. 视觉主题：木轮 · 春溪

- **调性**：宣纸底、剪纸人物、暖木色。整体朴素温柔，呼应歌词里的「朴素人家」「拙手削木」
- **配色**（`theme.palettes`）：paper 宣纸 / stream 溪青 / spring 春粉 / night 星夜 / dawn 晨光 / dusk 黄昏
- **贯穿元素：木轮** —— 每个场景都有它的变形，转场也是一只木轮从中心滚开

| 场景 | 木轮的样子 |
|---|---|
| 序 | 从左边滚进画面，停在正中，鼓点一响辐条就发光 |
| 人海 | 背景里像一只大钟；「匆忙」时飞转；「眉目好看」时变成瞳孔 |
| 溪水 | 太阳；落水的涟漪里隐约能看到辐条 |
| 副歌 | 中心的大轮，跟着节拍转，花瓣从轮心炸开 |
| 间奏 | 每一拍装上一根辐条，亲手削出这只轮子 |
| 主歌二 / 后副歌 | 变成单车的两只轮子，转速锁在节拍上（每拍 1/6 圈） |
| 桥段 | 月亮里隐约有辐条，地上留下两道车辙 |
| 尾声 | 朱红印章：外圈是轮圈，里面刻「木 · 柔」 |
| 转场 wheel | 擦除的边缘就是一圈带辐条头的木轮 |

## 4. 修改方式

- 每个画面事件都用 `s.cue("关键词")` 挂在歌词上：歌词时间改了，画面会自动跟着走
- 镜头只写开始时间，所以拖动一个镜头不会和别的镜头重叠或留空
- 参数位置：`data/project.js`；也可以在预览页里改好后导出
