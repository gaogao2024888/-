# 起雾的窗

**类型：** 现代表白歌
**结构：** 表白歌结构：主歌 1、预副歌、副歌、主歌 2、预副歌、副歌
**叙事方法：** 时间法：那晚、后来每晚、今晚
**一句话感想：** 喜欢你这句话，我只敢写在起雾的车窗上；这一次，我不擦了。
**核心意象（全曲只用这一个）：** 起雾的车窗上，写了又擦的「喜欢」
**副歌写法：** 金句总结型。两遍副歌只改最后一句

```
[Verse 1]
冬天的末班车
你坐在 我前面一排
围巾遮住半张脸
耳机线 垂到膝盖

[Pre-Chorus]
车窗慢慢起雾
我写下 一个喜
没写完 你动了一下
我赶紧 用袖口抹去

[Chorus]
我喜欢你
只敢说给 一扇起雾的窗
写了又擦 擦了又写
就是没敢 让你看

[Verse 2]
后来每晚 同一班车
你总在 第七站下
下车前 你会摘下一只耳机
像在等 有人叫住你

[Pre-Chorus]
今晚 第六站过了
车窗 又起了雾
我把那个喜欢 写完
这一次 没擦

[Chorus]
我喜欢你
只敢说给 一扇起雾的窗
写了又擦 擦了又写
这一次 换你来看
```

## 每句在干什么（没有一句废话）

| 段落 | 内容 |
|---|---|
| 主歌 1 | 四个镜头：末班车、坐前一排的她、遮住半张脸的围巾、垂到膝盖的耳机线 |
| 预副歌 1 | 他在雾上写了半个「喜」字，她一动，赶紧抹掉。心动，但不敢 |
| 副歌 | 金句「只敢说给一扇起雾的窗」；「写了又擦，擦了又写」是犹豫本身 |
| 主歌 2 | 后来每晚同一班车。她下车前总摘下一只耳机，像在等人叫她。这里埋了伏笔：她可能也在等他 |
| 预副歌 2 | 第六站过了，下一站她就要下车。他把「喜欢」写完，这一次没擦 |
| 副歌 2 | 前三句不变，最后一句从「就是没敢让你看」变成「这一次换你来看」 |

## 前后呼应

- 预副歌 1 写了半个「喜」字就抹掉，预副歌 2 把「喜欢」写完了，没擦。
- 主歌 2 里她摘下一只耳机，像在等人叫住她；结尾是他终于让她看见。她怎么回应，歌里不说，留白。
- 第六站对第七站：表白只剩最后一站的时间。

## 和上一首《到家了没》比，改掉了什么

- **删流水账：** 去掉「我伸手替你拿下来，你说谢谢」这种只交代过程、没有画面的句子。
- **删空话：** 去掉「这一次不绕弯了」「我喜欢你就是我喜欢你」这种口号。
- **一首歌只用一个核心意象：** 起雾的车窗。每一段都围着它写。
- **句子更短：** 每句大多不超过九个字。

## 押韵

情绪优先，不硬凑：
- 主歌 1 押怀来辙：排、盖。
- 预副歌 1 押一七辙：喜、去。
- 副歌用宽韵：窗、看。
- 主歌 2 隔句押：机、你。
