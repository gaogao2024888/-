# 起雾的窗

**类型：** 现代表白歌
**结构：** 表白歌结构：主歌 1、预副歌、副歌、主歌 2、预副歌、副歌
**叙事方法：** 时间法：那晚、后来每晚、今晚
**一句话感想：** 不敢说出口的喜欢，我只敢写在起雾的车窗上；这一次，我不擦了。
**核心意象（全曲只用这一个）：** 起雾的车窗上，写了又擦的那句话
**副歌写法：** 金句总结型。第一句就是歌名钩子；两遍副歌只改最后一句；第二遍副歌末尾把钩子再唱一遍收尾

```
[Verse 1]
末班车 载着半城灯火
你坐在 我前一排
围巾里 藏着半张脸
耳机线 垂进冬天

[Pre-Chorus]
车窗慢慢起了雾
我的指尖 替我开口
才写一半 你轻轻动了
我用袖口 把心事擦去

[Chorus]
起雾的窗
替我说了 不敢说的话
一笔一笔 写了又擦
你回头前 它就化了

[Verse 2]
后来每晚 同一班车
你总在 第七站下
下车前 你摘下一只耳机
把一半的安静 留给了谁

[Pre-Chorus]
第六站的灯 一盏盏往后退
窗上 又起了一层雾
我把那句话 写到最后一笔
指尖停住 没有擦

[Chorus]
起雾的窗
替我说了 不敢说的话
一笔一笔 写了又擦
这一次 等你回头看它
起雾的窗
等你回头
```

## 每段在干什么

| 段落 | 内容 |
|---|---|
| 主歌 1 | 只写画面：载着半城灯火的末班车，前一排的她，藏在围巾里的半张脸，垂进冬天的耳机线 |
| 预副歌 1 | 「指尖替我开口」：他在雾上写字，没说写什么；她一动，他用袖口把心事擦去 |
| 副歌 | 第一句就是歌名。起雾的窗替他说了不敢说的话，写了又擦，她回头前就化了 |
| 主歌 2 | 她下车前摘下一只耳机，「把一半的安静留给了谁」：像在等人叫她，不说破 |
| 预副歌 2 | 第六站的灯往后退，快到她下车的地方了。他把那句话写到最后一笔，没有擦 |
| 副歌 2 | 只改最后一句：从「它就化了」变成「等你回头看它」。末尾再唱一遍「起雾的窗，等你回头」收尾 |

## 这一版怎么写意境

- **不把话说满。** 全曲没有出现「喜欢你」三个字，只用「心事」「不敢说的话」「那句话」来代指。写的是什么，听的人自己懂。
- **意象 = 物 + 处境：** 半城灯火、垂进冬天的耳机线、替我开口的指尖、往后退的灯、化掉的字。
- **逻辑跳板：** 「耳机线垂进冬天」「把一半的安静留给了谁」，两样不相干的东西用一个动作连在一起。
- **意境和通顺两头顾：** 每句念出来仍是完整的话；「它」「那句话」都只指前面说过的东西。

## 押韵

情绪优先，不硬凑。副歌押发花辙：话、擦、化、它；预副歌 2 的「擦」接进副歌的韵。

```
Mandarin pop ballad, intimate and tender, male vocal, soft piano, warm acoustic guitar, subtle strings in chorus, 78 BPM
```
