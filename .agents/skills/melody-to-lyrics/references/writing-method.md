# 作词方法

旋律给的是「每句几个字、哪里长、哪里高」；这份文件管「写什么、怎么写才好」。要点部分整理自用户分享的作词教程（意象方法出自方文山的课），用自己的话概括，例句都出自《是你还是你》的实际创作过程。

## 1. 先搭结构

动笔前写下三样东西，后面每一句都对着它们检查：

- **歌名**（往往就是钩子）
- **主题，一句话说清**：例「雨后的夜，小城里的一切都把人带回同一个人；路走得再远，心里那盏灯从没熄过。」
- **情绪线**：起点 → 发展 → 转折 → 高潮 → 结局。

各段的常见分工（按实际旋律调整，旋律里没有的段落不要硬造）：

| 段落 | 分工 |
|---|---|
| 主歌一 | 第 1 句时间加地点，第 2 句人物加状态，后面是细节；只铺画面 |
| 预副歌 | 情绪往上推，句子可以一句比一句长 |
| 副歌 | 开头放钩子，中间展开，结尾放金句 |
| 主歌二 | 故事往前走，或者来一个转折（揭开真相） |
| 桥段 | 换个视角、反转 |
| 最后一遍副歌 | 重复第一遍，只改最后一句，让故事有结局 |
| 尾奏 | 和开头呼应 |

Suno 这类歌常常没有预副歌和桥段。这时让主歌一后半段承担预副歌的作用（旋律通常也在往上走），把转折交给主歌二。

## 2. 列意象库

写之前先列 15–30 个符合主题和场景的名词，这就是「血肉库」。写的时候只从库里取，句子用「名词 + 动作」搭起来，听的人闭上眼就能看见画面。

- 库外的词不要硬塞：画面突然跳到不相干的地方，意境就散了。
- 例（雨夜小城）：雨、伞、溪、旧巷、屋檐、胡琴、月色、长堤、柳、街灯 ／ 车票、抽屉、霓虹、酒杯、旧信、墨迹、西窗、烛火。

## 3. 选视角

| 视角 | 适合 | 特点 |
|---|---|---|
| 第一人称（我） | 心事、挣扎、回忆、成长 | 最常用，代入感强 |
| 第二人称（你） | 挽留、告白、遗憾、对听众喊话 | 像面对面说话，冲击力最大 |
| 第三人称（他／她／旁观） | 故事、古风、群像 | 有距离感和宿命感 |

可以混用：主歌用旁观的画面铺垫，预副歌转成第一人称，副歌切到第二人称直接打中人。

用户要求「少用你我他」时，主歌只写景，人称集中放在钩子和结尾。整首歌只在最关键的地方出现「你」，冲击会更大。

## 4. 画面代替直说：直白和说教

两种最常见的毛病：

- **直白**：把情绪、因果、结论一口气说完，不留余地。常见样子：
  - 直接写情绪：难过、孤单、伤太深、想你、忘不掉
  - 把因果说全：因为……所以……从此……
  - 用旧比喻还解释一遍：你像太阳，照亮我
- **说教**：「你应该」「记住」「人生就是要」「不要」；空泛口号；道德评判。

改法：

- 把情绪词换成能看见的东西和动作。

  | 直白 | 换成画面 |
  |---|---|
  | 这一刻忍不住想到你 | 拉的还是那年那支曲 |
  | 热闹过 也孤单过 | 霓虹里 举过酒杯 雨夜里 数过灯 |
  | 一缕思念吹入我心 | 雨声停在了街上 却还在心里响 |

- 讲故事，不讲道理：让听的人自己得出结论。
- 用「我后来才明白……」代替「你要……」；允许脆弱和疑问。
- 灰色地带：直白的钩子在音乐撑得住时也能很有力，比如「是我 忘不掉你」。可以留，但要有意识地选。

## 5. 钩子和金句

- **钩子**：副歌里反复出现、一听就记住的那句，常常就是歌名，比如「是你 还是你」。放在副歌旋律最突出的位置，两遍副歌都要有。
- **金句**：能单独拿出来发朋友圈的一句。通常是一个反差或一个意外的画面：
  - 雨声停在了街上 却还在心里响
  - 千万张脸经过 没有那一张
  - 一沓旧信写满了 从没寄去远方

## 6. 手法工具箱

| 手法 | 例句 |
|---|---|
| 以物写人：用东西代替说「一个人」 | 一盏孤灯 一副碗筷 晚安寄月光 |
| 拟人 | 夜雨轻轻叩着西窗 |
| 时空交错 | 每一滴 都落在从前 |
| 留白：只说一半，让听的人补 | 千帆过尽 灯火阑珊处 / 是你 |
| 反用成语 | 曲终人未散（反用「曲终人散」） |
| 化用古诗词 | 西窗、巴山夜雨（李商隐《夜雨寄北》）；蓦然回首、灯火阑珊处（辛弃疾《青玉案·元夕》）；春又绿了江岸（王安石《泊船瓜洲》）；过尽千帆（温庭筠《望江南》） |
| 贯穿全曲的意象 | 灯：街灯亮又熄 → 雨夜里数过灯 → 一盏灯未曾熄 → 灯火阑珊处 |
| 首尾呼应 | 开头「雨刚停」，主歌末尾「雨声停在了街上 却还在心里响」 |
| 揭开真相 | 主歌二揭开「信写满了却从没寄出」，最后一遍副歌改成「最后一封 终于寄出去 / 给你」 |

化用要改写，不要整句照搬名句；要选听众大致熟悉的出处。

## 7. 打磨清单

写完逐句过一遍：

- 有没有硬凑的韵脚？念出来像不像人话（「穿过旧巷里」不如「拐进旧巷里」）。
- 句子长短有没有变化？（字数由旋律定，断句可以调）
- 每句唱完有没有气口？
- 有没有倒字？（`check` 会提示，再唱一遍确认）
- 有没有直接抒情的词？删掉，换成画面。
- 「的、了、吗、吧」能删就删；旋律需要那一拍时才留。
- 抽象词换成具体的意象加动作；长句拆短或短句合并，制造节奏变化。
- 念三遍，标出所有不顺的地方。

## 8. 和用户协作

- 方向没定时，一次给 2–3 版不同方向，比如执念、释怀、盼重逢，或者秋夜、江边、夏夜。每版说清押什么韵、用了什么画面。
- 每个位置的字数都一样，所以各版的句子可以混搭，要告诉用户这一点。
- 用户认可的句子保留，只改有问题的地方，并说明依据：字数、倒字、直白，还是硬凑韵。
- 用户自己写的句子，先查字数和倒字，再给最小改动，比如补一个「的」、换一个字。
- 交付时说清楚哪些地方可靠（重复出现的副歌），哪些是估的（被乐器盖住的主歌）。
