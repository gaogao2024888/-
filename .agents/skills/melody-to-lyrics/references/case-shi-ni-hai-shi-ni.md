# 实战案例：《是你还是你》

在新对话里继续这首歌，先读这份文件。不需要原音频：同目录的 `case-shi-ni-hai-shi-ni.spec.txt` 存着人工核对过的旋律，`template` 就能重建校验模板。

## 素材

- Suno 生成的歌（作者 badboy2026），3:24，1=B（B 大调），约 128 BPM，温柔男声。
- 编曲：响指、尤克里里、二胡，和弦 1-6-2-5（来自 Suno 风格标签）。
- 文件标签里的原歌词只存到主歌第一个字「月」，原词没有参考价值，只沿用了歌名。

## 这段旋律上的声调坑

| 位置 | 旋律 | 不要放 |
|---|---|---|
| 副歌第 1、6 句 | 倒数第二个字前下行五度；最后一个字上行五度 | 倒数第二字放第二声；末字放第三声 |
| 副歌第 2、7 句 | 第 5 个字前下行四度；末字下行五度落长音 | 这两处放第二声（「名」会听成「命」，「痕」会听成「恨」） |
| 副歌第 4 句（6 字） | 第 4 个字上行四度；第 5、6 个音是全曲最高的长音 | 第 4 字放第三声；第 5、6 字最好用开口音 |
| 副歌第 8 句 | 倒数第二个字前上行五度 | 第三声 |
| 副歌第 9 句 | 第 3 个字前上行大六度 | 第三声 |
| 主歌一第 7 句（5 字） | 最后一个音是高长音 | 闭口音（i u ü） |
| 主歌二第 3 句 | 最后一个字上行四度 | 第三声 |
| 主歌二第 4 句 | 第 6 个字前下行五度 | 第二声 |

## 用户的偏好（从这次合作里总结）

- 喜欢画面感强、文艺唯美、有意境的词；不要直白、说教、无脑堆砌。
- 少用你、我、他：主歌最好只写景，人称留给钩子和结尾。
- 押韵：可以双押、三押，也接受宽韵、斜押、换韵，偏 R&B 的婉转；不能为押韵硬凑，但也不能完全不押。
- 要有钩子和能单独拿出来的金句；最后要能直接贴进 Suno。
- 合作方式：先给几版不同方向挑；保留他认可的句子；改动要说明理由。
- 后来提供了一份作词教程，要求按它来写，要点见 `writing-method.md`。

## 歌词演变

```
[Verse 1]
雨刚停 风很轻 巷口亮起灯几盏
我撑着旧油纸伞 走过小桥边
桥下流水还那么慢
像极了那一年的春天
你站在我的面前
说好了要陪我走很多年
一阵风吹散
从此后人海茫茫 你我再难相见

[Chorus]
走过了很多城 见过很多人
热闹过 也孤单过 心底留个位置
原来兜兜转转 是你还是你
是你 还是你~
从来没有走远
听过了很多歌 写过很多信
每一首情歌 每一行字迹 都是你
人来人往 眼里只看得见你

[Verse 2]
```

### 3. 按作词方法重写的完整版（最新）

```
[Verse 1]
雨刚停 风很轻 街头的灯又亮起
撑着伞路过小溪 拐进旧巷里
谁家檐下胡琴响起
拉的还是那年那支曲
月色漫过了长堤
柳下的影子 被月光拉长
街灯亮又熄
雨声停在了街上 却还在心里响

[Chorus]
车票塞满抽屉 换过几座城
霓虹里 举过酒杯 雨夜里 数过灯
兜兜转转一圈 又回到原地
是你 还是你～
一盏灯 未曾熄
旧信纸起了皱 墨迹还清晰
每一封 第一行 都是同一个名字
千万张脸经过 没有那一张
千帆过尽 灯火阑珊处
是你

[Verse 2]
塞北的雪 江南的岸 走成了流年
一沓旧信写满了 从没寄去远方
西窗下 把烛火剪亮
等谁来 话巴山夜雨

[Final Chorus]（前 8 句同副歌）
最后一封 终于寄出去
给你
```

- 设计：
  - 主题：雨后小城，景物都把人带回同一个人。
  - 意象有两条线：灯（街灯亮又熄 → 数过灯 → 一盏灯未曾熄 → 灯火阑珊处），信（旧信 → 第一行同一个名字 → 从没寄出 → 终于寄出）。
  - 主歌不出人称。
  - 最后一遍副歌只改最后两句。
- 全部 32 句对上旋律，没有倒字。
- 两处闭口音落长高音是故意的：「是你 还是你」是歌名钩子；「街灯亮又熄」和「一盏灯 未曾熄」呼应。
